# Shaadi Cards

Wedding invitation & Save-the-Date maker (free, offline) and AI pre-wedding photoshoots (credits), for the Indian wedding market.

- Flutter + Riverpod 3 (codegen) + go_router + freezed
- Supabase (anonymous auth, Postgres + RLS, Storage, Edge Functions, pg_cron)
- RevenueCat on top of Google Play Billing / Apple IAP

See [SETUP.md](SETUP.md) to run it and [DECISIONS.md](DECISIONS.md) for design choices.
